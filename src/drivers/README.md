# Hardware driver snapshots

This directory contains reproducible snapshots of third-party hardware drivers.
Each snapshot retains its upstream license and must be kept separate from the
project-owned integration packages.

- `odin_ros_driver`: Manifold Tech Odin1 ROS driver.
- `scout_ros2`: a snapshot of the Hive-Matrix-AI repository's remote default
  branch, including the exact `third_party/agilex_ugv_sdk` revision selected by
  that branch.
