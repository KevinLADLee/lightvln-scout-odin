# Security

Report vulnerabilities privately to [KevinLADLee](mailto:kevinladlee@gmail.com)
with the affected commit and reproduction steps. Do not include credentials
or private camera recordings in public issues.

The Web console and inference service have no built-in authentication or TLS.
Use a trusted robot network or an authenticated gateway. Follow
[hardware validation](docs/hardware.md#enable-motion-after-validation) before enabling motion.
